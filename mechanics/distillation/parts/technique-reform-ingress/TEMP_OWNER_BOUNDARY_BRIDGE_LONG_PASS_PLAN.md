## Owner Stop-Lines

`aoa-techniques` owns reusable public technique atoms: the compact move,
inputs, outputs, contract, risk, validation posture, and adaptation hints.

Adjacent owners stay outside the atom:

| Owner | Authority held outside `aoa-techniques` |
|---|---|
| `Agents-of-Abyss` | constitutional center doctrine, ecosystem law, center-side Method-growth, federation posture |
| `aoa-skills` | accepted skill workflows, triggers, package shape, activation, command behavior |
| `aoa-evals` | proof categories, empirical verdicts, eval harnesses, pass/fail claims, report authority |
| `aoa-routing` | advisory navigation, dispatch hints, route selection products |
| `aoa-memo` | memory objects, recall truth, temporal relevance, writeback semantics |
| `aoa-kag` | derived provenance-aware graph or retrieval substrate meaning |
| `aoa-playbooks` | scenarios, questlines, campaigns, recurring compositions, fallback choreography |
| `aoa-agents` | role contracts, profiles, progression, checkpoint and recurrence contracts at the agent layer |
| `abyss-stack` or runtime owners | deployment, service lifecycle, local host behavior, infrastructure truth |
| local project owners | local consent, adoption, deletion, deprecation, rollout, retention, and operational execution |

Allowed bridge wording names enough context for the next owner to understand
what kind of handoff exists. It stops before writing that owner's policy,
workflow, proof, memory, route, or runtime behavior.

## Repair Gate

Accept source repair only when one of these direct-read failures appears:

- a bundle performs an adjacent owner's action instead of producing a technique
  output;
- wording turns an example owner into universal topology law;
- a checklist requires skill activation, eval verdict, route mutation, memory
  writeback, runtime mutation, or local owner consent as if the technique owned
  it;
- a technique cannot tell a small agent where to stop before sibling authority
  begins;
- support files contradict the `TECHNIQUE.md` stop-line;
- relation wording forces a sequence or dependency that belongs in a direct
  relation repair packet, not in broad review prose.

Hold as non-defects:

- examples that mention AoA owners as adaptation context;
- support notes that point to skills, evals, routing, memory, KAG, playbooks,
  or agents as later destinations;
- provenance terms from mechanics, if the technique contract remains atomic;
- lack of empirical local-model proof;
- lack of a new owner-boundary schema field.

## Per-Shelf Rhythm

Use this exact loop for every wave:

1. Reopen this file and mark the active wave.
2. Read the route stack:
   - `AGENTS.md`;
   - `mechanics/AGENTS.md`;
   - `mechanics/distillation/AGENTS.md`;
   - `mechanics/distillation/parts/AGENTS.md`;
   - [Technique Reform Ingress](README.md);
   - `techniques/AGENTS.md`;
   - nearest trunk `AGENTS.md`.
3. Read each selected bundle:
   - `TECHNIQUE.md`;
   - local checklist;
   - local example;
   - `notes/second-context-adaptation.md`;
   - `notes/origin-evidence.md` or external-origin notes when present.
4. Read prior shelf packets:
   - direct-read migration review;
   - landed pilot review;
   - selector/relation wave or repair packet;
   - portability bridge packet when the shelf was covered;
   - bundle anatomy packets when shape pressure appears.
5. For each bundle, write one row in the working notes:
   - technique-local atom;
   - allowed bridge;
   - authority held outside;
   - verdict: `holds; no repair`, `source repair candidate`, or `separate
     relation repair candidate`.
6. Apply the repair gate.
7. Write one review packet for the wave.
8. Update `reviews/README.md` and this plan.
9. Update [Technique Reform Ingress](README.md) only when the contour actually
   changes.
10. Validate the smallest honest surface:
    - `git diff --check`;
    - public-safety grep over touched files;
    - `python -m unittest tests.test_distillation_mechanics_topology`;
    - `python scripts/validate_repo.py` for structural or index changes.
11. Land each completed wave as its own commit/PR/merge during the execution
    pass.
