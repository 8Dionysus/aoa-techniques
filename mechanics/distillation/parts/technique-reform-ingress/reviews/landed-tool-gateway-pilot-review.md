## What The Twenty-Eighth Pilot Proved

- `tool-use/` can exist as a compact tree trunk without becoming a junk drawer
  for every tool-adjacent technique.
- A singleton shelf can be valid when direct reading proves a single atomic
  technique is the honest semantic neighborhood.
- Broad `agent-workflows` can now function as a frontmatter review lane rather
  than a direct dumping ground for every workflow-shaped bundle.
- The gateway leaf is easier for humans and small agents to find because it
  sits beside tool-use posture instead of beside execution chains, governance
  gates, or instruction surfaces.
- Generated projection rows can converge on current paths without adding
  `tree_path`, `family`, capability, substrate, execution-profile, or risk
  frontmatter.

## Remaining Weaknesses

- `AOA-T-0065` can still drift into a full security platform if scanner,
  reputation, policy, tenancy, or dashboard language becomes central.
- It can still drift into runtime deployment ownership if lifecycle setup,
  hosting, config distribution, or local stack operation becomes the main
  object.
- It can still drift into connector registry or marketplace curation if
  publication-time discovery and runtime gateway mediation collapse.
- It remains promoted rather than canonical; the readiness note still asks for
  a second live adopter beyond the donor and documentation-first adaptation.
- Future `tool-use` shelves must still pass direct reading; this singleton
  does not authorize broad tool-use migration by analogy.
