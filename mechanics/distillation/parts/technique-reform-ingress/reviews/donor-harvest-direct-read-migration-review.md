leaves start from reviewed session evidence or a reviewed harvest packet and

## Why This Shelf Holds

- The common object is reviewed-session continuity, not generic execution.
- The four leaves form a readable sequence: harvest candidate units, preserve
  the packet contract, lift progression evidence, and optionally add an adjunct
  quest overlay.
- Each leaf already names its refusal boundary. The shared refusal is that
  reviewed session artifacts remain evidence, not live memory, role authority,
  playbook doctrine, or routing law.
- The shelf gives a small agent a better local neighborhood: every leaf answers
  what survives a session boundary and how to keep that survivor reviewable.

## Continuity Trunk Fit

`continuity/` already owns techniques about context, review truth, handoff
state, donor material, and capability availability surviving a state boundary.
`donor-harvest` fits that trunk because the state boundary is a reviewed
session closeout: the leaves decide which donor objects, packet fields,
evidence deltas, and overlays may carry forward.

The path placement should not imply a `domain` remap. These four can remain
`domain: agent-workflows` because their original review lane is still a
post-session workflow lane. The tree path only makes the continuity browsing
shape clearer.

## Watch Signals

- `AOA-T-0075` can drift into generic summarization if reusable units and
  evidence anchors stop being central.
- `AOA-T-0077` can become a catch-all packet schema if optional fields start
  acting like sibling verdicts.
- `AOA-T-0084` can become progression doctrine if unlock hints or verdicts
  grant rights, role status, or routing authority.
- `AOA-T-0085` can become playbook or quest authority if flavor becomes larger
  than the underlying reviewed base.
- All four remain promoted, not canonical; future canonical review still needs
  another independent downstream context.
