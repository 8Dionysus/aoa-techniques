# Semantic Review Packets

This directory holds authored semantic-review packets that used to sit flat in
`docs/`.

They remain human review surfaces for bounded working sets. They do not change
technique status, frontmatter, generated manifests, or bundle contracts by
themselves.

`docs/review/SEMANTIC_REVIEW_GUIDE.md` stays the public guide for the family, while
this directory owns the review packets as part of the Distillation
technique-reform ingress route.
