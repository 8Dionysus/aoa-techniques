# Shadow Review Packets

This directory holds authored shadow-review packets that used to sit flat in
`docs/`.

They remain human review surfaces for canonical caution seams. They do not
turn caution into policy metadata, scoring, or generated authority.

`docs/review/TECHNIQUE_SHADOW_GUIDE.md` and generated
`docs/readers/review/SHADOW_PATTERNS.md` stay
the public reader route, while this directory owns the review packets as part
of the Distillation technique-reform ingress route.
