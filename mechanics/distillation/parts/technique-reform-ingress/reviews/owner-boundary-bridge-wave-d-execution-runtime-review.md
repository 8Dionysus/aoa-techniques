## Cross-Owner Read

Wave D keeps execution discipline inside `aoa-techniques` while leaving live
execution authority outside.

The local atom may plan, slice, dry-run, check, confirm, invoke, model a graph,
derive ready work, render a pre-start view, diagnose host readiness, start a
bounded local stack, or compare a baseline and additive profile. It may not
accept a skill workflow, install a command, mutate host policy, decide
dispatch, own a service, publish runtime truth, govern deployment, score a
product, or claim empirical proof.

Adjacent split:

- `aoa-skills` owns accepted executable workflows, triggers, packages,
  activation, and command behavior.
- `aoa-routing` owns dispatch products and route selection; task graphs and
  ready queues are technique-local planning aids, not routing law.
- `aoa-playbooks` owns scenarios, recurring compositions, and fallback
  choreography.
- `aoa-evals` owns proof categories, empirical verdicts, benchmark reports,
  and pass/fail authority.
- runtime owners such as `abyss-stack` own services, deployments, launcher
  behavior, monitoring, host policy, and operator runbooks.
- local project owners own consent, adoption, rollout, retention, and actual
  execution.

## Wave Findings

`agent-workflows-core` holds because each core move has a stop-line. The broad
change workflow stops at report and validation evidence; the TDD slice stops
at one behavior; the single-shot posture refuses hidden session state; the
confirmation gate requires a fresh visible mutation seam; shell composability
stays about explicit I/O rather than shell doctrine.

`intent-chain` holds because intent handling remains pre-execution. The chain
normalizes intent into artifacts and dry-run contract checks, while new-intent
rollout remains a bounded expansion checklist. Neither leaf grants live
execution permission.

`ready-work-graphs` holds because graph and queue are review surfaces, not
dispatch owners. The accepted `AOA-T-0050 requires AOA-T-0049` relation
remains a direct object dependency from the selector/relation lane; this wave
does not add sequence vocabulary or route policy.

`runtime-truth-lifecycle` holds because each runtime-adjacent leaf is smaller
than runtime ownership. Render review is read-only and pre-start, host doctor
is diagnostic, lifecycle is bounded/local/operator-triggered, and additive
benchmarks are comparison contracts rather than performance governance.
