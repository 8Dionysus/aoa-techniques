# Candidate Intake

This part owns active Distillation intake for public-safe candidate packets.

Nothing here is canon. Use this directory only for active candidate intake that
still needs review, normalization, source evidence, and the normal atom/topology
gate before it can speak as technique canon.

## Current State

There are no active packet roots in this part.

The former closed packet roots are preserved under
[closed incoming packets](https://github.com/8Dionysus/aoa-techniques/blob/feffba63dc22fd921512ba5a3ff1b5d78606f93b/mechanics/distillation/legacy/archive/closed-incoming-packets/README.md).

## How To Use This Directory

- Put new public-safe candidate packets here only while they are still active
  Distillation quarantine or staging material.
- Shape a packet as one bounded donor family or source-pressure family, not a
  mixed backlog.
- Keep packet docs, evidence notes, support manifests, registries, verdicts,
  and handoff notes inside the packet root.
- Use the landed `techniques/**/TECHNIQUE.md` bundle for current technique
  meaning.
- Use Distillation legacy when you need the final record for a closed packet.
- Start a new Distillation intake only when fresh public evidence can name one
  bounded atom/topology route.

## Packet Shape

A packet may start small, but it should converge toward:

- `README.md` for status, scope, owner boundary, and stop line
- `docs/` for candidate notes, closeout memos, and planting order
- `support/manifest.json` for packet metadata and activation state
- `support/registry.json` for candidate slugs, verdict lanes, and bundle
  presence
- `support/CODEX_HANDOFF.md` only when a future agent needs a bounded operator
  route

Do not put generated catalogs, canonical technique bundles, private dumps, or
closed packet archives here.

## Stop Line

Do not use this part as a long-term archive. Once a packet closes, preserve its
public-safe evidence under the owning legacy route and return this part to
active intake only.
