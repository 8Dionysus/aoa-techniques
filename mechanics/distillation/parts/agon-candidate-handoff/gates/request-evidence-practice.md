## Atom

Ask for the smallest missing evidence object that could change the current
review state.

The move has four fields:

- reviewed claim or decision point
- missing evidence object
- why that object matters
- return condition after the object appears or stays absent

## Portable Core

The portable core is not Agon law. It is a small review move:

1. Name the claim or decision that is currently under-supported.
2. Ask for exactly one evidence object.
3. Explain what that object would settle, narrow, or reopen.
4. State what happens if the object is unavailable.

This works outside OS Abyss when the orchestrator supplies the claim, current
review state, and acceptable evidence format.
