# Agon Candidate Gate Cards

Gate cards are one-candidate Distillation checks. They sit between an Agon
requested-only candidate and any future technique bundle.

A gate card may name an atom and topology. It must not change Agon candidate
status, define Agon law, or draft the bundle.
