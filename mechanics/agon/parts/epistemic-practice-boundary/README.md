# Agon Epistemic Practice Boundary

Technique candidates describe reusable thinking practices. They do not execute workflows, issue eval verdicts, or mutate memory.

## Boundary

This part keeps epistemic Agon practice inside the technique layer. It may shape
reviewable thinking-practice candidates, but it must not create live protocol
authority, proof verdicts, memory writeback, rank/scar effects, KAG promotion,
or ToS canon.
