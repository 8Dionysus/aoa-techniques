# Release Support

This package owns the `aoa-techniques` side of the cross-project Release-support
mechanic: installation, release ritual, rollback rehearsal, public-support
posture, and post-release watch surfaces that remain bounded by owner consent.

- [Installation Techniques](INSTALLATION_TECHNIQUES.md): staged landing,
  migration safety, smoke gates, rollback, and replay-audit practice.
- [Sovereign Release Techniques](SOVEREIGN_RELEASE_TECHNIQUES.md): release
  ritual, decision sealing, rollback rehearsal, and post-release watch.

Release-support can prepare and document release-shaped practice. It does not
define GitHub-only release truth, approve releases by itself, or make unverified
public claims.
