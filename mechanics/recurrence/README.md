# Recurrence

This package owns recurrence observation mechanics that feed technique review
without becoming status or promotion authority.

- [Recurrence Live Observation Producers](RECURRENCE_LIVE_OBSERVATION_PRODUCERS.md):
  producer signals for technique review.
- [Recurrence Review Decision Closure](RECURRENCE_REVIEW_DECISION_CLOSURE.md):
  closure posture for recurrence-fed review decisions.

Recurrence may observe the cross-layer candidate README and its generated
registry index together. The README remains the decision route; the generated
registry is evidence for counts and gates only.
