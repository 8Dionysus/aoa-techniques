# Recurrence

This package owns the `aoa-techniques` side of recurrence: observation and
closure mechanics that feed technique review without becoming status,
promotion, proof, memory, routing, or runtime authority.

Recurrence here is thinner than the center mechanic in `Agents-of-Abyss`.
The center owns recurrence law: return to a valid anchor, explicit re-entry,
bounded continuity, and source ownership. This repo only owns technique-layer
signals that may help review candidate intake, overlap holds, canonical
pressure, and decision closure.

## Boundary

Recurrence may observe the cross-layer candidate README and its generated
registry index together. The README remains the decision route; the generated
registry is evidence for counts and gates only.

This package may point from recurrence signals to local technique review. It
does not create candidates, release holds, change technique status, claim
canonical readiness, or treat generated evidence as review.

## AoA relation

`Agents-of-Abyss` owns recurrence law and the current recurrence owner-request
packet. The current center queue has no direct
`ORQ-RECURRENCE-TECHNIQUES-*` request, so local recurrence pressure is recorded
as candidate-only observation pressure in [Owner Request Receipts](../REQUEST_RECEIPTS.md).

Stable reusable recovery practices may later become technique bundles, but only
through the normal `techniques/**/TECHNIQUE.md` review path.
