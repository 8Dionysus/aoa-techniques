# Live Observation Producers

This part names producer inputs that may feed technique review. The signals are
advisory and must remain weaker than authored decision surfaces.

## Producer Inputs

- `mechanics/distillation/parts/cross-layer-candidate-ledger/README.md`
- `mechanics/distillation/parts/cross-layer-candidate-ledger/generated/cross_layer_candidate_registry.min.json`
- `mechanics/audit/parts/promotion-readiness-matrix/README.md`
- `generated/technique_promotion_readiness.min.json`

## Local Rule

The cross-layer generated registry is observation evidence for counts, gates,
waves, and holds. It is not a decision surface, does not release overlap or
incubation holds, and does not authorize promotion.

Promotion-readiness JSON can expose review pressure. It does not replace the
promotion-readiness matrix, canonical review guide, or owner judgment.

## Outputs

This part may produce:

- a review signal
- a candidate-intake refresh prompt
- an overlap-hold followthrough prompt
- a canonical-pressure followthrough prompt

It may not produce:

- a technique candidate by itself
- a status change
- a released hold
- a canonical readiness verdict
- an owner acceptance claim
