# Recurrence Roadmap

This roadmap records future contour for the `aoa-techniques` recurrence
package. It does not change technique status, generated contracts, recurrence
law, or validator behavior by itself.

## Current Contour

Recurrence is the local route for recurrence observation and review-closure
pressure that can feed technique review without becoming authority.

- `live-observation-producers` is the local home for advisory producer inputs
  that may feed technique review.
- `review-decision-closure` is the local home for recurrence-fed review packet
  closure posture.
- The cross-layer registry remains observation evidence only; the corresponding
  README remains the decision route.
- Recurrence pressure is currently non-ORQ candidate-only pressure in this repo,
  not a direct AoA owner-request landing.

## Next Work

1. Keep recurrence references pointed at part-local homes as more generated
   beacon or receipt surfaces appear.
2. Add a new part only if repeated technique-layer recurrence signals no longer
   fit observation producers or review decision closure.
3. Promote a reusable recurrence practice into `techniques/` only after it can
   name one atomic move, likely domain, likely kind, family posture,
   capability, substrate, execution profile, risk posture, relations, and
   validation.

## When Time Comes

- Add examples only when reviewed recurrence evidence can stay advisory and
  public-safe.
- Route SDK carry to `aoa-sdk`, memo recall to `aoa-memo`, proof verdicts to
  `aoa-evals`, runtime return to the runtime owner, and playbook choreography to
  `aoa-playbooks`.
- Reassess this roadmap after recurrence evidence repeatedly identifies the
  same missing review or recovery move.

## Out Of Scope

- Technique candidates from generated registry evidence alone.
- Releasing overlap holds from recurrence observation.
- Promotion-readiness JSON as canonical review.
- AoA recurrence law, SDK carry, memo recall, routing dispatch, proof verdicts,
  runtime return, or playbook choreography as local authority.
