# Recurrence Roadmap

This roadmap records future contour for the `aoa-techniques` recurrence
package. It does not change technique status, generated contracts, or validator
behavior by itself.

## Current State

- `live-observation-producers` is the local home for advisory producer inputs
  that may feed technique review.
- `review-decision-closure` is the local home for recurrence-fed review packet
  closure posture.
- The cross-layer registry remains observation evidence only; the corresponding
  README remains the decision route.
- Recurrence pressure is currently non-ORQ candidate-only pressure in this repo,
  not a direct AoA owner-request landing.

## Next Honest Moves

- Keep recurrence references pointed at part-local homes as more generated
  beacon or receipt surfaces appear.
- Add a new part only if repeated technique-layer recurrence signals no longer
  fit observation producers or review decision closure.
- Promote a reusable recovery practice into `techniques/` only after it can name
  one atomic move, likely domain, likely kind, family posture, capability,
  substrate, execution profile, risk posture, relations, and validation.

## Stop-lines

- Do not create technique candidates from generated registry evidence alone.
- Do not release overlap holds from recurrence observation.
- Do not treat promotion-readiness JSON as canonical review.
- Do not import AoA recurrence law, SDK carry, memo recall, routing dispatch,
  proof verdicts, runtime return, or playbook choreography into this package.
