# Audit Roadmap

This roadmap names Audit future pressure for `aoa-techniques`. It does not
change bundle status, promotion verdicts, generated readiness, or public proof
by itself.

## Current Contour

Audit is the local route for promotion-readiness visibility, evidence sprinting,
evidence ledgers, and canon-pressure review around technique bundles.

The active package already has:

- promotion-readiness matrix and matrix-expansion lanes
- external evidence sprint and ledger parts
- review surfaces that can expose readiness pressure without mutating status
- stop-lines that keep proof verdicts and owner acceptance outside this repo
- a canonical retro-audit part that checks already-canonical rows for
  metadata/evidence/verdict coherence without turning Audit into proof authority

The weak roadmap shape came from a valid next-pass note. It now needs to read
as a contour surface because Audit is a repeated route in technique reform.

## Next Work

1. Keep the active part split stable while route links settle across docs,
   quests, recurrence, and validators.
2. Keep the now-closed `v0.4 matrix-expansion lane` stable in the
   [Promotion Readiness Matrix](parts/promotion-readiness-matrix/README.md)
   and reopen it only when generated readiness shows a newer promoted bundle
   outside the pack matrix.
3. Run external evidence searches only through the
   [External Evidence Sprint Runbook](parts/external-evidence-sprint-runbook/README.md)
   and record real searched lanes in the
   [External Evidence Ledger](parts/external-evidence-ledger/README.md).
4. Re-run [Canonical Retro Audit](parts/canonical-retro-audit/README.md) after
   status, maturity, validation strength, or evidence declarations move for
   canonical rows.
5. Replace the current promotion wave runbook only after the remaining active
   Wave A candidates close or the lead queue changes.

## When Time Comes

- Add a package-local generated audit summary only if repeated review evidence
  needs the same lookup shape across several technique shelves.
- Ask `aoa-evals` for proof-facing work only when Audit findings need
  proof-strength levels rather than readiness posture.
- Promote an audit-shaped practice into `techniques/` only after it is one
  atomic review move with stable inputs, outputs, risks, and validation.

## Out Of Scope

- Status flips from audit pressure alone.
- Proof verdicts or public proof.
- Owner-local remediation authority.
- Memory, runtime, role, KAG, playbook, or routing truth.
- Treating generated readiness as canonical review.
- Turning evidence ledgers into a second roadmap.
