# Method-Growth

This package owns the `aoa-techniques` side of the cross-project Method-growth
mechanic: moving repeated practice toward explicit technique adoption, owner
landing, retention, pruning, or technique-to-skill handoff without confusing
practice meaning with execution authority.

- [Technique To Skill Handoff](TECHNIQUE_TO_SKILL_HANDOFF.md): handoff posture
  between reusable technique canon and bounded skill workflows.
- [Technique Adoption Boundaries](TECHNIQUE_ADOPTION_BOUNDARIES.md): owner
  stop-lines for adopting technique patterns.
- [Technique Pattern Adoption](TECHNIQUE_PATTERN_ADOPTION.md): reusable adoption
  precedent mechanics.
- [Technique Retention Checks](TECHNIQUE_RETENTION_CHECKS.md): checks for
  whether an adopted pattern should remain active.
- [Technique Obsolescence](TECHNIQUE_OBSOLESCENCE.md): bounded removal and
  deprecation mechanics.

Method-growth can route a practice toward adoption or handoff. It does not make
another owner accept the practice, and it does not turn a technique into a skill.
