# Antifragility Legacy

This directory preserves antifragility source lineage that fed the active
`aoa-techniques` package.

Start with [Index](INDEX.md) and [Distillation Log](DISTILLATION_LOG.md). Open
`raw/` only when the original donor or wave wording matters.

Legacy material is not active antifragility law and not technique canon. Active
behavior lives in the package root and `parts/`.
