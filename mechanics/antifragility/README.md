# Antifragility

This package owns the `aoa-techniques` side of the cross-project Antifragility
mechanic: bounded stress, chaos, degraded-mode, and recovery pressure that helps
expose where reusable practice should be captured.

- [Chaos Wave 1 Program](CHAOS_WAVE1_PROGRAM.md): bounded stress program shape
  and owner-routing posture.

Antifragility may surface stress signals and reusable recovery candidates. It
does not become proof, owner-local cleanup authority, or a universal health
score.
