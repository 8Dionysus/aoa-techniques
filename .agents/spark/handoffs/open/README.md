# Open Spark Handoffs

Place active Spark handoff packets here.

Each packet should name the scenario, reason for handoff, scope read, findings,
likely files, validation already run, validation still needed, stop-line, and a
suggested next prompt.

Open handoffs are not public obligations by themselves. Route durable follow-up
to `QUESTBOOK.md`, a mechanic part, a decision record, or the owning source
surface when the owner accepts it.
