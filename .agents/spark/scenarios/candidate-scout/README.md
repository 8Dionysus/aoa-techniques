# Spark Scenario: candidate-scout

Use `candidate-scout` to map donor, legacy, or mechanic-local material that
might later become one technique.

## Scope

One donor cluster, legacy packet, mechanic part, or candidate seam.

## Done Signal

Likely active homes, rejected material, portability concerns, source questions,
and next owner route are named.

## Stop-line

Do not perform deep semantic distillation or canon promotion inside scout mode.

## Handoff Route

Write a handoff when the material needs synthesis, active doctrine changes,
bundle drafting, owner acceptance, or public-safety review.

## Validation

Run shape or link checks when the scout updates an index. Otherwise report a
manual provenance pass.
