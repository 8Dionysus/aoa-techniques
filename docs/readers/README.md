# Generated Readers

This district holds generated or builder-backed Markdown reader companions.

Authored doctrine, contracts, and guides stay in `docs/` root. Generated JSON
stays in [generated](../../generated/).

| [repo](repo/README.md) | repository docs route reader companion |
| [review](review/README.md) | shadow/caution reader companion |

| [runtime](runtime/README.md) | local runtime card reader companion |
| [source-lift](source-lift/README.md) | section, checklist, example, and evidence-note reader companions |
