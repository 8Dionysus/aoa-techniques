# minimal local-pattern-adoption-gate

```yaml
local_pattern_adoption_gate:
  pattern: mechanics package card
  local_owner: technique mechanics maintainers
  behavior_surface: mechanics package README entry shape
  source_evidence: reviewed package-card decision and live mechanics usage
  owner_consent: explicit
  compatibility: local card uses technique-layer ownership rather than center authority
  rollback_or_quarantine: revert the package-card wording or keep the pattern in the mechanic roadmap
  retention_watch: review after the next two mechanics package passes
  result: shadow
```

Why this example stays bounded:

- it gates one pattern against one local behavior surface
- it treats shadow as a real outcome rather than forced adoption
- it does not activate a skill, route, proof verdict, runtime change, or sibling owner
