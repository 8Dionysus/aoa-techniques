# single-scoped-evidence-reference checklist

Use this checklist before offering a reference inside a bounded review.

- [ ] One reviewed claim or decision point is named.
- [ ] Exactly one evidence reference is offered.
- [ ] The reference is concrete enough to inspect, quote, rerun, or reject.
- [ ] The relevance statement explains why the reference matters to the claim.
- [ ] The scope statement says what the reference can support.
- [ ] The limit statement says what the reference cannot support.
- [ ] The reliance condition says what must happen before the reference is used.
- [ ] The output does not offer a bundle of references.
- [ ] The reference is not treated as proof, verdict, or source-truth transfer.
- [ ] The output does not issue route, memory, runtime, skill, rank, scar, KAG, ToS, eval, or Agon law effects.
