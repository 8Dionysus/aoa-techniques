# Adverse Effects Review

## Technique
- id: AOA-T-0091
- name: workspace-root-ingress-and-mutation-gate
- current role: bounded canonical default

## Review focus

Review the effects of making `workspace-root-ingress-and-mutation-gate` a default technique where ingress and mutation guard orient and gate; they do not author owner truth.

## Failure modes

- the technique is applied before the reviewed object or owner boundary is named
- downstream users treat the technique as broader authority than its one move
- adjacent owner surfaces are silently imported as requirements
- local AoA vocabulary is mistaken for a portability requirement

## Negative effects

- overuse can slow review by adding ritual where the current evidence is already enough
- under-scoped outputs can create false confidence because the move looks tidy
- downstream readers may overread the supporting evidence as proof of adjacent systems

## Misuse patterns

- using the technique as permission, verdict, route law, memory truth, runtime repair, or owner acceptance
- collapsing several objects into one output to avoid a harder owner decision
- skipping explicit absent, hold, defer, rollback, or re-entry posture when the technique requires it
- treating sibling-repo evidence as hidden dependency for standalone users

## Detection signals

- the output cannot name the single object or boundary it acts on
- proof, routing, runtime, skill, playbook, memory, KAG, ToS, or Agon authority appears in the result
- reviewers cannot separate the technique output from the downstream owner action
- the cited support no longer matches the current owner surface or live repo state

## Mitigations

- keep the move to one bounded object and one visible output
- cite owner surfaces only as evidence or handoff targets, not as imported authority
- preserve hold, defer, rollback, or re-entry language when evidence is incomplete
- route proof verdicts, runtime action, memory writeback, playbook choreography, skill execution, and owner acceptance to their owning repos

## Recommendation

Keep the canonical bundle and use this note as one bounded watch surface. Future
changes should sharpen the move boundary without widening it beyond ingress and mutation guard orient and gate; they do not author owner truth.
