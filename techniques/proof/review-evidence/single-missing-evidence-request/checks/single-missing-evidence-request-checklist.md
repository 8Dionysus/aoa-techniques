# single-missing-evidence-request checklist

Use this checklist before asking for missing evidence inside a bounded review.

- [ ] One reviewed claim or decision point is named.
- [ ] The current review state or evidence gap is visible.
- [ ] Exactly one missing evidence object is requested.
- [ ] The object is concrete enough to provide or declare absent.
- [ ] The request explains how the object would change, narrow, or reopen review.
- [ ] The return condition says what happens if the object appears.
- [ ] The return condition says what happens if the object remains unavailable.
- [ ] The request does not ask for broad research or every possible source.
- [ ] Missing evidence is not treated as proof of failure.
- [ ] The output does not issue proof, verdict, route, memory, runtime, skill, rank, scar, KAG, ToS, or Agon law effects.
