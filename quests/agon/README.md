## Strict Source Defaults

Markdown quest sources in this lane use `quest_markdown_contract_v1`. They may
point to this README for defaults, but each source still needs non-empty
`Quest`, `Owner Route`, `Next Action`, `Acceptance Evidence`, and `Stop-lines`
sections.

Agent edits, Agon stop-lines, validation, and closeout live in
[agon/AGENTS](AGENTS.md).
